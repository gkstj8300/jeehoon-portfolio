## 개요

Claude Code와 Codex로 개발하다 보면 매일 같은 질문을 마주합니다. "이 작업은 어떤 모델로 돌려야 하지?" 두 서비스 모두 최상위 모델부터 가볍고 빠른 모델까지 여러 등급을 제공하고, 같은 모델 안에서도 추론 강도를 조절할 수 있어서 선택지가 생각보다 많습니다. 이 글에서는 2026년 10월 공식 문서를 기준으로 두 서비스의 모델 라인업을 정리하고, 작업 종류별로 모델을 고르는 기준을 세워봅니다.

```list
이 글을 읽고 나면 다음을 할 수 있습니다.
- Claude와 Codex의 모델 등급과 각 모델의 용도를 구분한다.
- 성능·비용·속도를 기준으로 작업에 맞는 모델을 고른다.
- 추론 강도(effort)를 조절해 같은 모델로 비용과 품질의 균형을 맞춘다.
```

## 이름만 보고 고르면 생기는 일

모델을 고를 때 흔히 쓰는 방법은 세 가지입니다.

- **무조건 최상위 모델**: 가장 똑똑한 모델을 쓰면 결과도 가장 좋을 것이라고 생각하는 방식입니다.
- **무조건 기본값**: 도구가 정해준 모델을 그대로 쓰는 방식입니다.
- **가장 싼 모델**: 비용을 줄이려고 경량 모델부터 쓰는 방식입니다.

```caution
세 방법 모두 절반만 맞습니다. 최상위 모델은 단순 작업에서 느리고 비싸며, 경량 모델은 어려운 작업에서 재시도가 늘어 오히려 총비용이 커질 수 있습니다. 또 같은 모델이라도 추론 강도에 따라 결과와 비용이 크게 달라집니다. 모델 이름보다 "작업에 맞는 등급과 추론 강도"를 고르는 것이 핵심입니다.
```

## 모델을 고르는 세 가지 기준

### 1. 성능 등급

```point
성능 등급이란?
두 서비스 모두 모델을 "최상위 / 주력 / 경량" 단계로 나눠 제공합니다. 최상위 모델은 가장 어려운 추론과 오래 걸리는 에이전트 작업을, 주력 모델은 일상 개발을, 경량 모델은 요약·분류처럼 빠르고 많이 처리해야 하는 작업을 맡습니다.
```

### 2. 추론 강도(effort)

```point
추론 강도(effort)란?
같은 모델이라도 답하기 전에 얼마나 깊이 생각할지를 정하는 설정입니다. 두 서비스 모두 low부터 max까지 단계를 제공하며, 높일수록 정확도는 올라가지만 응답 시간과 토큰 사용량도 늘어납니다.
```

추론 강도는 모델마다 기본값이 다르다는 점을 꼭 기억해야 합니다. 예를 들어 Claude Opus 5.5의 기본값은 medium이라, 어려운 작업에서는 high 이상으로 직접 올려 주는 것이 좋습니다.

### 3. 비용과 속도

```point
가격을 읽는 법
가격은 "100만 토큰당 입력 / 출력" 단위로 표기합니다. 이번에 비교하는 일곱 모델은 모두 출력 가격이 입력 가격의 5배입니다. 응답이 긴 작업일수록 출력 가격이 총비용을 좌우합니다.
```

## Claude 모델 라인업

![Claude 모델 라인업](/images/posts/claude-codex-models/claude-lineup.webp)

Anthropic은 공식 문서에서 "어떤 모델을 써야 할지 모르겠다면 Claude Opus 5.5부터 시작하고, 더 높은 추론 강도에서도 부족하면 Claude Fable 5.1을 쓰라"고 안내합니다. 네 모델 모두 컨텍스트 1M 토큰, 최대 출력 128K 토큰을 지원합니다.

### Claude Fable 5.1

```point
가장 어려운 추론과 장시간 에이전트 작업용 최상위 모델
사고(thinking)가 항상 켜져 있고 기본 추론 강도는 high입니다. 가격은 입력 $10 / 출력 $50으로 가장 비싸고, 응답도 가장 느린 편입니다.
```

여러 단계를 스스로 판단해야 하는 긴 에이전트 작업이나, Opus 5.5로 추론 강도를 올려도 풀리지 않는 문제에 꺼내 쓰는 모델입니다. 모든 작업의 기본값으로 두기보다는 "마지막 카드"로 쓰는 편이 비용 면에서 유리합니다.

### Claude Opus 5.5

```point
장시간 에이전트 코딩과 지식 작업을 위한 기본 추천 모델
입력 $4 / 출력 $20으로 Fable 5.1보다 훨씬 저렴하면서 사고가 항상 켜져 있습니다. 기본 추론 강도는 medium입니다.
```

Fast 모드를 켜면 같은 Opus 5.5 모델로 출력 속도를 최대 2.5배까지 높일 수 있습니다. 더 작은 모델로 바꾸는 것이 아니라 같은 모델을 빠르게 돌리는 방식이라 품질은 그대로이고, 가격은 입력 $8 / 출력 $40으로 두 배가 됩니다.

### Claude Sonnet 5.5

```point
속도와 지능의 균형을 맞춘 주력 모델
입력 $2 / 출력 $10에 기본 추론 강도는 high입니다. 일상적인 코딩, 에이전트 작업, 업무 자동화를 빠르게 처리합니다.
```

기능 구현, 테스트 작성, 코드 수정처럼 하루에 수십 번 반복하는 작업에 잘 맞습니다.

### Claude Haiku 5.5

```point
대량·저지연 작업을 위한 경량 모델
입력 $0.10 / 출력 $0.50부터 시작하는 가장 저렴한 모델로, 응답도 가장 빠릅니다. 기본 추론 강도는 medium입니다.
```

분류, 추출, 라우팅처럼 짧고 많은 요청을 처리할 때 씁니다. 표시 가격은 프롬프트 10만 토큰 이하 기준이며, 이를 넘으면 입력 $0.50 / 출력 $2.50이 적용됩니다.

## Codex 모델 라인업

![Codex 모델 라인업](/images/posts/claude-codex-models/codex-lineup.webp)

OpenAI는 2026년 9월 GPT-6 Astra를 공개하며 Codex의 모델 구성을 GPT-6 계열로 바꿨습니다. 세 모델 모두 컨텍스트 1.05M 토큰, 최대 출력 128K 토큰을 지원합니다.

### GPT-6 Astra

```point
코드·앱·리서치 전반의 가장 까다로운 작업용 최상위 모델
입력 $10 / 출력 $50으로 Claude Fable 5.1과 같은 가격대입니다. 추론 강도는 low부터 max까지 고를 수 있습니다.
```

Codex의 가장 강력한 모델입니다. 다만 공식 문서가 GPT-6.1 Sol을 "Astra에 가까운 성능을 더 낮은 비용으로" 내는 모델로 소개하고 있어, 반복되는 복잡한 작업은 Sol로 처리하고 Astra는 Sol로 부족할 때 꺼내는 편이 경제적입니다.

### GPT-6.1 Sol

```point
Astra에 가까운 성능을 더 낮은 비용으로 내는 추천 주력 모델
입력 $2 / 출력 $10으로 Claude Sonnet 5.5와 같은 가격대입니다. Codex 앱에서는 추론 강도를 Light부터 Ultra까지 고를 수 있습니다(Max·Ultra는 설정에 따라 제공).
```

공식 문서가 반복적이고 오래 걸리는 작업에 고려하라고 안내하는 모델로, 복잡한 개발 작업을 꾸준히 맡기기 좋습니다.

### GPT-6 Luna

```point
요약·추출·집중형 코딩 같은 대량 작업에 가장 효율적인 경량 모델
입력 $0.10 / 출력 $0.50으로 Claude Haiku 5.5와 같은 가격대입니다. 추론 강도에 none(추론 없음) 단계가 있어 가장 가볍게 돌릴 수 있습니다.
```

무료·Go 요금제 사용자도 데스크톱 앱에서 선택할 수 있는 모델입니다(제공되는 경우). 이 밖에 은퇴한 gpt-5.4를 대체하는 GPT-6 Sol(gpt-6-sol)도 함께 제공됩니다.

```caution
Codex는 모델 교체가 빠르게 진행 중입니다. gpt-5.4와 gpt-5.4-mini는 8월 31일, GPT-5.3-Codex-Spark는 9월 14일에 은퇴했고, GPT-5.5도 10월 14일 ChatGPT 로그인 기반 Codex에서 은퇴했습니다(API 키 사용은 영향 없음). 설정 파일에 예전 모델 이름이 남아 있다면 GPT-6 계열로 바꿔 두세요.
```

## 한눈에 비교하기

![100만 토큰당 가격 비교](/images/posts/claude-codex-models/price-comparison.webp)

두 라인업을 나란히 놓으면 가격대가 정확히 맞물린다는 점이 눈에 띕니다.

```list
- 최상위: Claude Fable 5.1 = GPT-6 Astra (입력 $10 / 출력 $50)
- 주력: Claude Sonnet 5.5 = GPT-6.1 Sol (입력 $2 / 출력 $10)
- 경량: Claude Haiku 5.5 = GPT-6 Luna (입력 $0.10 / 출력 $0.50)
- Claude Opus 5.5(입력 $4 / 출력 $20)는 Codex에 대응하는 가격대가 없는 중간 단계
- 컨텍스트는 Claude 1M, GPT-6 1.05M 토큰으로 사실상 같은 수준이고, 최대 출력은 모두 128K 토큰
```

가격과 컨텍스트만으로는 우열을 가리기 어렵습니다. 결국 차이는 "내 작업에서 어느 모델이 적은 재시도로 끝까지 해내는가"에서 납니다. 같은 가격대의 두 모델을 실제 작업 몇 개로 직접 비교해 보는 것이 가장 정확합니다.

## 실전 적용: 작업별 모델 선택

![작업별 모델 선택 가이드](/images/posts/claude-codex-models/model-guide.webp)

### 어려운 문제

설계, 난도 높은 디버깅, 대규모 리팩터링처럼 실수 비용이 큰 작업입니다. Claude에서는 Opus 5.5의 추론 강도를 high 이상으로 올리고, Codex에서는 GPT-6.1 Sol을 high 이상으로 씁니다. 그래도 부족할 때 Fable 5.1이나 Astra로 올립니다.

### 일상 구현과 반복 작업

기능 구현, 테스트 작성, 코드 수정처럼 자주 반복하는 작업입니다. Claude Sonnet 5.5나 GPT-6.1 Sol로 충분하며, 속도가 중요하면 추론 강도를 낮춥니다.

### 대량·단순 작업

로그 요약, 데이터 추출, 분류, 요청 라우팅처럼 짧고 많은 작업입니다. Claude Haiku 5.5나 GPT-6 Luna가 비용과 속도 모두에서 유리합니다.

### 도구에서 모델 바꾸기

Claude Code와 Codex 모두 세션 중에 `/model` 명령으로 모델을 바꿀 수 있고, 설정 파일로 기본 모델을 정해 둘 수 있습니다.

```js
// Claude Code - 세션 중 모델 전환
/model   // 모델 선택 메뉴 열기
/fast    // Opus 빠른 출력 모드 켜기·끄기 (더 작은 모델로 바꾸는 것이 아님)

// .claude/settings.json - 프로젝트 기본 모델 지정
{
	"model": "claude-opus-5-5"
}
```

```js
// Codex CLI - ~/.codex/config.toml
model = "gpt-6.1-sol"
model_reasoning_effort = "high"

// 세션 중에는 /model 로 모델과 추론 강도를 함께 바꿀 수 있습니다.
```

```caution
싼 모델이 항상 싼 것은 아닙니다. 요청 한 번의 단가가 낮아도 재시도와 수정이 늘어나면 작업 하나를 끝내는 총비용은 오히려 커질 수 있습니다. 비용은 요청 단위가 아니라 "완료된 작업 단위"로 비교하세요.
```

## 모델을 고를 때 기억할 네 가지

**모델보다 추론 강도를 먼저 조절합니다.** 경량 모델로 내려가기 전에 같은 모델의 추론 강도를 낮춰 보세요. Anthropic 문서에 따르면 최신 모델은 낮은 추론 강도로도 이전 세대의 높은 강도와 비슷하거나 더 나은 결과를 내는 경우가 많습니다.

**기본값을 확인합니다.** Opus 5.5와 Haiku 5.5는 추론 강도 기본값이 medium, Fable 5.1과 Sonnet 5.5는 high입니다. 같은 이름의 설정이라도 모델마다 출발점이 다르므로, 중요한 작업에서는 값을 직접 지정하는 것이 안전합니다.

**같은 가격대끼리 비교합니다.** Fable 5.1과 Astra, Sonnet 5.5와 6.1 Sol, Haiku 5.5와 Luna는 가격이 같습니다. 두 도구를 함께 쓴다면 같은 가격대 모델끼리 같은 작업을 맡겨 보고, 결과가 더 나은 쪽을 그 작업의 기본값으로 정하면 됩니다.

**모델 정보는 금방 바뀝니다.** 최근 두 달 사이에만 Codex에서 모델 네 개가 은퇴했습니다. 선택 기준은 문서로 남겨 두되, 모델 이름과 가격은 분기마다 공식 문서로 다시 확인하는 습관이 필요합니다.

```list
핵심 정리
- 두 서비스 모두 "최상위 / 주력 / 경량" 세 단계로 모델을 제공하며, 가격대가 서로 정확히 맞물린다.
- 어려운 작업은 Opus 5.5·GPT-6.1 Sol을 높은 추론 강도로 쓰고, 부족할 때 Fable 5.1·Astra로 올린다.
- 일상 작업은 Sonnet 5.5·GPT-6.1 Sol, 대량 작업은 Haiku 5.5·GPT-6 Luna가 효율적이다.
- 모델을 바꾸기 전에 추론 강도부터 조절하고, 비용은 완료된 작업 단위로 비교한다.
- 모델명과 가격은 자주 바뀌므로 공식 문서를 기준으로 주기적으로 다시 확인한다.
```
